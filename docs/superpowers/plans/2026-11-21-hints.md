# Hints Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Hint button under failed stages that asks a configurable command-line model for a leveled, no-code hint.

**Architecture:** `Config.hint` from `anvil.yml` (or `claude -p` detected); `src/hints.ts` builds the prompt (pure)
and gathers code from the bare repo; a streaming `POST /api/repos/:repo/runs/:id/hint` runs the command (one at a
time); the page adds the button and keeps hint state across re-renders.

**Spec:** `docs/superpowers/specs/2026-11-21-hints-design.md`

## Global Constraints

- Levels 1–3 only; caps: log 20 KB (tail), diff 30 KB, file 50 KB, previous 3 × 4 KB, output 20 KB, prompt budget
  `maxPromptKB` (default 150) KB with code taking the remainder; timeout 180 s; one hint at a time (409).
- Command run with `sh -c` in an empty temp dir; stdin = prompt.
- No new dependencies. Branch `hints`; commit at the end.

## Review Focus

- Prompt over budget: code is cut first and the cut is stated: Task 2 `code fills only the remaining budget`.
- Binary and large files skipped: Task 2 `skips binary and large files`.
- A failing or hanging command ends the stream with a clear line: Task 3 tests.
- A second concurrent request gets 409: Task 3 test.
- Model output with HTML is escaped: Task 4 test `hintHtml escapes`.
